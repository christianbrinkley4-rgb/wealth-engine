Goal: make christianbrinkleync.com #1 for the Medicare searches that produce
appointments in the Triad. Researched 2026-10-08 via live Google/Bing result
observation. No third-party volume tool was used; opportunity is scored
qualitatively (volume x intent x winnability for a local agent site), NOT from
invented search-volume numbers. Rankings below are what was actually observed

## What the research proved (3 findings that change the plan)

1. **Freshness is winning RIGHT NOW.** For AEP/2027 queries, pages published
   or updated in the last 3-7 days are outranking established domains:
   serenelivingtips.com (published Oct 7) ranks #1 for "medicare open
   enrollment 2026 dates"; trinsurance.com (an AGENCY, updated 3 days ago)
   ranks #1 for "medicare 2027 changes". This is a time-limited window tied
   to AEP season. Publish 2027 content THIS WEEK.
2. **Agent domains CAN win.** help.ihealthagents.com (an agent platform,
   updated 15 days ago) ranks #1 for "medicare part d donut hole 2026
   explained", above Motley Fool and NCOA. Direct, fresh answers beat big
   brands when the query is specific.
3. **Medicare Agents Hub owns every "medicare agent [city] NC" query.**
   It holds #1 for Greensboro AND High Point. Christian is not listed there.
   Getting listed puts him INSIDE the #1 result instead of fighting it.
   (Separate off-site action; the citation campaign should prioritize this.)

Poisoned query warning: "medicare help greensboro nc" returns drug-rehab
directory spam (detoxtorehab.com). Do NOT target the word "help" with a city;
target "medicare agent greensboro nc" instead.

## The 5 highest-leverage new pages to build

### Page 1: /medicare-changes-2027
- **Title:** "Medicare Changes for 2027: What You Need to Know Before Open Enrollment"
- **Why:** Freshness window is open NOW; an agency (trinsurance.com) holds #1
  with a 3-day-old page. This is the single most winnable high-volume query.
- **Must answer:**
  1. What is changing for Medicare in 2027? (Part D deductible $615 to $700;
     OOP cap $2,100 to $2,400; MA avg premium down to ~$12; star ratings
     formula changes; marketing rules loosening Oct 1, 2026)
  2. When is open enrollment for 2027 coverage? (Oct 15-Dec 7, 2026)
  3. Will my plan change in 2027? (Read the ANOC; link /anoc)
  4. What should I do before December 7? (drug list, doctor check, review)
  5. Where can I get help in Greensboro? (local CTA, phone)
- **Compliance:** all figures from CMS announcements; cite sources; no plan
  recommendations.

### Page 2: /medicare-advantage-vs-medigap-greensboro-nc
- **Title:** "Medicare Advantage vs. Medigap in Greensboro, NC (2027 Guide)"
- **Why:** Follows the paulbinsurance.com model (localized comparison page
  ranking nationally). National query is owned by medicareagentshub.com #2;
  the local version has no strong incumbent.
- **Must answer:**
  1. Which is better, Medicare Advantage or Medigap? (honest framework)
  2. What does each cost per month in North Carolina? (cite NC figures:
     MA avg $12.86/mo 2026; Medigap Plan G ~$130/mo Greensboro)
  3. Can I switch from Medicare Advantage back to Medigap later?
     (underwriting warning)
  4. Which Greensboro doctors and hospitals take which plans? (check-first CTA)
  5. How do I decide? (CTA to free review)
- **Compliance:** educational only; no carrier or plan recommendations.

### Page 3: /medicare-supplement-plans-greensboro-nc
- **Title:** "Medicare Supplement (Medigap) Plans in Greensboro, NC for 2027"
- **Why:** #1 is medicareboutique.com, a thin lead-gen page (crawled 1 day
  ago, beatable with real substance). High buying intent.
- **Must answer:**
  1. What Medigap plans are available in Greensboro? (G, N most popular)
  2. How much does Plan G cost in Greensboro? (cite NC averages; no invented
     quotes — use published ranges only)
  3. Plan G vs. Plan N: which should I pick?
  4. When is the best time to buy? (6-month open enrollment, guaranteed issue)
  5. Can I get help comparing? (local CTA)
- **Compliance:** never invent premiums; use published CMS/Plan Finder ranges
  with sources and dates.

### Page 4: /medicare-part-d-donut-hole-2027
- **Title:** "Is There Still a Medicare Donut Hole in 2027?"
- **Why:** help.ihealthagents.com PROVES an agent site can hold #1 here with
  a fresh, direct answer. People still search "donut hole" constantly.
- **Must answer:**
  1. Is there still a donut hole in 2027? (No — eliminated Jan 1, 2025)
  2. How does Part D work now? (3 stages: deductible, initial, catastrophic)
  3. What is the 2027 Part D deductible and out-of-pocket cap? ($700 max
     deductible; $2,400 cap)
  4. What changed from 2026? ($615 to $700; $2,100 to $2,400)
  5. How do I pick a Part D plan for 2027? (formulary check CTA)
- **Compliance:** figures from CMS; cite sources.
