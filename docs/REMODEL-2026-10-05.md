# Site remodel, October 5, 2026

Branch: `claude/new-session-72enll`, built on top of `master` (6916deb). It is `master` plus four commits, so `master` can fast-forward to it if nothing new lands on `master` first. This session was not allowed to push `master` itself.

## What changed

**Design system.** New palette: Carolina pine, warm cream, and one honey accent. Contrast ratios are measured and noted at the top of `app/system.css`, and every text pairing meets WCAG AA. Headlines use Fraunces. Body text stays Atkinson Hyperlegible (chosen earlier for low-vision readers). The existing color variables were re-pointed, so every page picked up the palette. The header, mobile menu, sticky call bar, footer, page hero, page close and disclosure box are all rebuilt.

**Motion.** Scroll reveals use one observer for the whole site and stay visible without JavaScript. Pages ease in when you navigate between them, skipped on first load so the first paint isn't delayed. Buttons, cards and FAQ accordions animate, and the hero has light parallax. `prefers-reduced-motion` turns all of it off.

**Signature pieces.**
1. Homepage: "Seven months. One window." Pick a birthday month and the enrollment window draws itself. Tap a month to see when coverage starts. Shows the Medigap window too.
2. Homepage: the Part B late-penalty slider. It uses the same tested math as `/part-b-penalty`.
3. `/taxes-and-retirement`: a scroll-driven retirement timeline (50, 55, 59½, 62, 63, 65, 67, 70, 73+).
4. Homepage plan-check preview, plus a quiz restyle with lettered options, animated progress and step transitions.

**New pages.**
- `/learn`, the Learning Hub: 36 entries grouped by situation, with search. New articles appear in it automatically.
- `/taxes-and-retirement` plus three explainers: Social Security taxes, RMDs, Roth conversions.
- `/about`, rebuilt photo-first in Christian's voice.
- `/schedule`, rebuilt around the embedded Cal.com calendar.

**Conversion and measurement (brief section 6).**
- Analytics allow-list: 4 events became 11. Added `quiz_start`, `quiz_step`, `quiz_abandon`, `quiz_complete`, `booking_open`, `booking_complete` and `article_cta_click`. Quiz events carry only a quiz id and step number, and a test enforces that.
- Plan check and `/start` fire funnel events. I verified this in a browser with a stubbed `gtag`: the start, step, abandon and complete events arrived in order.
- The plan check's email capture now counts as a lead (`generate_lead`). It shares an event id with the server's copy.
- The Cal.com webhook sends a server-side `booking_confirmed` event once per new booking. Retries and reschedules aren't counted.
- The sticky call bar now shows on every Medicare page, town pages included. Before, `/medicare-in/*` hid it.
- The homepage's primary button goes to `/plan-check`. The hero photo is preloaded.
- Turnstile loads only on pages with a form.
- Town pages no longer repeat the LocalBusiness JSON-LD.
- Sitemap and canonicals: removed the `/medicare-nc-towns/` trailing slash.

**Copy.**
- Removed every em and en dash from visitor-facing copy and emails. Ranges now read "to", and sentences that broke were fixed by hand.
- Short license lines read "NC Life & Health" everywhere, from `AGENT.licenseLine`.
- The TPMO disclaimer renders only from `TPMO_DISCLAIMER` in `lib/agent.ts`, through `components/TpmoDisclaimer.tsx`. The 14 hard-coded copies are gone.

**Checks.** `npm run lint`: 0 errors, the same 3 warnings as `master`. `npm test`: 484 passed. `npm run build`: 141 pages. Screenshots: 54 routes at 390, 768 and 1440, with no sideways scrolling and no console errors.
